## 기능

- **한국 · 미국 주식** — KRX, NASDAQ, NYSE 종목을 지원합니다
- **종목명 검색** — 종목 코드를 몰라도 `삼성`, `apple`처럼 이름으로 검색해 추가할 수 있습니다
- **여러 종목 동시 표시** — 한 창에 여러 종목을 세로로 쌓아 표시합니다
- **자동 갱신** — 30초 또는 1분 주기로 시세를 갱신합니다
- **평단가 수익률** — 종목별 평균 매입가를 입력하면 현재 수익률을 함께 표시합니다
- **알림** — 종목별 목표가 돌파를 상향·하향 자동으로 감지하고, 당일 등락률 급등락 알림도 제공합니다. OS 네이티브 알림으로 전달됩니다
- **투명 · 드래그** — 테두리 없는 창을 원하는 위치로 옮길 수 있으며 항상 위에 표시됩니다
- **투명도 조절** — 10~100% 범위에서 조절합니다
- **레이아웃 테마 5종**과 **대체 레이블 모드**를 제공합니다 ([표시 모드](#표시-모드) 참고)
- **종목명 · 종목코드 숨기기**를 선택할 수 있습니다
- **설정 자동 저장** — 종목 목록, 평단가를 포함한 모든 설정이 자동으로 저장됩니다

색상은 한국식 기준을 따릅니다. **상승은 빨강, 하락은 파랑**이며 미국 종목에도 동일하게 적용됩니다.

## 사용법

### 1. 종목 검색 및 추가

앱을 실행하면 설정 패널이 표시됩니다.

<img src="screenshots/settings.png" width="380" alt="설정 패널" />

검색창에 종목명 또는 코드를 입력하면 한국과 미국 종목이 함께 검색되며 각각 🇰🇷, 🇺🇸 배지가 붙습니다. 그 외 거래소에 상장된 종목도 검색되며 🌐 배지로 표시됩니다.

<img src="screenshots/search.png" width="380" alt="종목 검색 및 추가" />

1. `삼성`, `apple`, `005930` 등을 입력한 뒤 결과를 클릭해 **목록에 추가**합니다
2. 필요하면 종목별 **평단가**와 **🔔 목표가**를 입력합니다
3. 원하는 만큼 종목을 추가합니다 (`✕`로 삭제)
4. **테마**와 **갱신 주기**(30초 · 1분)를 선택합니다
5. 필요하면 **종목명/종목코드 숨기기**, **비즈니스 모드**, **급등락 알림** 기준, **OS알림**, **투명도**를 조절합니다
6. **시작**을 클릭합니다

### 2. 시세 화면

<img src="screenshots/theme-minimal.png" width="380" alt="시세 화면 (미니멀 테마)" />

- 가격은 **상승 시 빨강, 하락 시 파랑**으로 표시되며 미국 종목에는 `$`가 붙습니다
- 평단가를 입력한 종목은 아래에 `평단 330,000 -14.85%` 형태로 수익률이 표시됩니다
- 해당 종목의 장이 마감된 경우 국가와 무관하게 `· 장마감`이 표시됩니다
- **창을 드래그**해 원하는 위치로 옮길 수 있습니다
- 상단 **⚙**로 설정 화면에 돌아가고, **✕**로 종료합니다

## 알림

두 가지 트리거가 독립적으로 동작하며, 모두 OS 네이티브 알림(macOS 알림 센터, Windows 토스트)으로 전달됩니다.

**목표가 알림** — 종목에 🔔 목표가를 입력하면 해당 가격을 통과할 때 알림이 발생합니다. 상향과 하향을 모두 자동으로 감지하므로 방향을 따로 지정할 필요가 없습니다. 한 번 발생한 뒤에는 가격이 목표가에서 1% 이상 벗어나야 다시 무장되어, 목표가 부근에서 가격이 오르내려도 알림이 반복되지 않습니다.

**급등락 알림** — 당일 등락률이 ±N%(기본 5%)에 도달하면 발생합니다.

시작 직후 첫 조회는 기준값만 잡고 알림을 발생시키지 않습니다. 따라서 오버레이를 시작하는 시점에 이미 충족된 조건으로는 알림이 오지 않습니다.

비즈니스 모드를 켜면 알림 문구도 함께 치환됩니다. 제목이 `📈 시세 알림` 대신 `Metrics`가 되고, `목표가 도달`은 `임계값 도달`로 바뀝니다. 알림 배너에도 주식 관련 표현이 남지 않습니다.

## 캐릭터 모드

바탕화면에 캐릭터를 띄우고 머리 위에 대표 종목의 현재가와 수익률을 표시합니다. 설정의 **캐릭터 모드**로 켭니다.

- 기본은 제자리에 서 있습니다. `└ 알아서 돌아다니기`를 켜면 화면 안을 산책합니다
- **캐릭터를 클릭하면 조종 모드**가 됩니다 — `← →` 이동, `↑` 점프, `F` 때리기, `G` 공 던지기, `Esc` 해제
- 드래그로 옮길 수 있고, 놓으면 바닥으로 떨어집니다
- 수익률에 따라 표정과 몸 색이 바뀝니다

### 친구와 함께 보기

같은 방에 접속한 친구의 캐릭터가 내 화면에 함께 나타나고, 서로 때리거나 공을 던져 맞힐 수 있습니다.

접속에는 Supabase Realtime을 씁니다. **접속 정보는 이 저장소에 들어 있지 않습니다.** 방을 여는 사람이 무료 프로젝트를 하나 만들어 초대 코드를 나눠주는 방식입니다.

**방을 여는 사람**

1. [supabase.com](https://supabase.com)에서 프로젝트를 만듭니다 (무료 플랜으로 충분합니다)
2. 대시보드 상단의 **Connect** 버튼, 또는 **Settings**에서 두 값을 복사합니다
   - **Project URL** — **Settings → Data API**의 `API URL` 또는 `Project URL`입니다. `https://xxxxxxxx.supabase.co` 형태이며, `/rest/v1` 같은 경로가 붙어 있어도 그대로 붙여넣으면 됩니다
   - **Publishable key** — `sb_publishable_`로 시작합니다
     (예전에 만든 프로젝트라면 `anon` `public` 키가 대신 있습니다. `eyJ`로 시작하는 긴 문자열이며 그대로 쓰면 됩니다)
3. 설정의 `코드 만들기`를 눌러 둘을 입력하면 초대 코드가 생성됩니다
4. 그 코드를 친구에게 전달합니다

> **`sb_secret_`로 시작하는 키나 `service_role` 키는 절대 쓰지 마세요.** 이 키는 모든 보안 정책을 우회하며, 초대 코드는 친구에게 전달되는 값이라 그대로 유출됩니다. 앱이 입력 단계에서 막아주긴 하지만 애초에 복사하지 않는 것이 좋습니다.

**친구**

초대 코드를 붙여넣고 이름을 적은 뒤 `연결`을 누릅니다.

> 전송되는 값은 화면상의 상대 위치(0~1), 바라보는 방향, 이름, **수익률 퍼센트**뿐입니다. 평단가·수량·금액은 전송하지 않으며 각자 기기에만 남습니다.

위치는 캐릭터가 움직이는 동안에만 초당 10회 전송되고, 멈춰 있으면 아무것도 보내지 않습니다. 무료 플랜의 메시지 한도로 충분한 이유입니다.

## 표시 모드

**비즈니스 모드**를 켜면 주식 용어가 일반적인 지표 용어로 치환되어, 시세창이 아닌 일반 대시보드처럼 표시됩니다.

| 기본 | 비즈니스 모드 |
|------|---------------|
| 평단 | `baseline` |
| 수익률 | `rate` |
| 변동 | `delta` |
| 장마감 | `synced` |
| 항목 | `metric` |

종목명 · 종목코드 숨기기를 함께 켜면 화면에 종목을 식별할 수 있는 정보가 남지 않습니다. 아래는 스프레드시트 테마에 두 옵션을 모두 적용한 예시입니다.

## 빌드

### Windows — 설치 파일 (.exe)

```bash
npm run dist:win
```

산출물: `dist/Metrics Setup 1.0.0.exe` (x64 NSIS 설치 관리자)

### Windows — 무설치 압축 (.zip)

```bash
npm run dist:win:zip
```

산출물: `dist/Metrics-1.0.0-win.zip` (x64, 설치 불필요)

압축을 해제한 뒤 폴더 안의 `Metrics.exe`를 실행합니다. 실행 파일이 옆의 DLL과 `resources` 디렉터리에 의존하므로 폴더 전체를 함께 유지해야 합니다.

### macOS — 디스크 이미지 (.dmg)

```bash
npm run dist:mac
```

산출물: `dist/Metrics-1.0.0-universal.dmg` (Apple Silicon · Intel 공용 universal 바이너리)

### 코드 서명

배포 파일은 **유료 인증서로 서명되지 않았으며 공증(notarization)도 되어 있지 않습니다.** 따라서 두 운영체제 모두 최초 실행 시 경고가 표시됩니다.

- **Windows** — SmartScreen 경고가 표시됩니다. `추가 정보` → `실행`을 선택합니다.
- **macOS** — 빌드 시 ad-hoc 서명이 적용됩니다. Apple Silicon에서는 서명이 없으면 실행 자체가 불가능하기 때문입니다. 다만 Gatekeeper는 여전히 확인되지 않은 개발자로 표시하므로, 최초 실행은 앱 **우클릭 → 열기 → 열기**로 승인해야 합니다.

| 플랫폼 | 산출물 |
|--------|--------|
| Windows (설치형) | `dist/Metrics Setup 1.0.0.exe` |
| Windows (무설치) | `dist/Metrics-1.0.0-win.zip` |
| macOS | `dist/Metrics-1.0.0-universal.dmg` |

별도의 API 키나 추가 설정 없이 동작합니다.

## 커스터마이징

- **앱 이름 · 버전 변경** — `package.json`의 `build.productName`과 `version`을 수정한 뒤 다시 빌드합니다
- **아이콘 재생성** — `python3 make-icon.py <원본이미지>`를 실행하면(Pillow 필요) `build/icon.png`, `icon.ico`, `icon.icns`가 생성됩니다
- **스크린샷 재생성** — `npx electron scratch_capture.js` 실행 후 `python3 scratch_compose.py`를 실행합니다
- **데모 애니메이션 재생성** — `npx electron scratch_demo.js`(실제 앱을 조작하며 녹화) 실행 후 `python3 scratch_demo_gif.py`를 실행합니다
- **시세 조회 로직** — `main.js`의 `fetchQuote`와 `naver.js`에 있습니다

## 데이터 출처 및 면책

시세는 **네이버 금융의 비공식 엔드포인트**(`polling.finance.naver.com`, `m.stock.naver.com`)에서 가져옵니다. 공개된 API가 아니므로 사전 공지 없이 변경되거나 중단될 수 있습니다.

이 프로젝트는 네이버와 어떠한 제휴 관계도 없으며 네이버의 승인을 받지 않았습니다. 시세 데이터의 정확성, 완전성, 실시간성을 보장하지 않으며 지연될 수 있습니다. **투자 판단의 근거로 사용해서는 안 됩니다.** 본 애플리케이션의 사용에 따른 책임은 전적으로 사용자에게 있습니다.
